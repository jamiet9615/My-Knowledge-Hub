# raw — 原始資料區

此資料夾用來保存來源原件。請依知識領域建立子資料夾。

## 使用規則
- 原始來源不可由 Agent 覆寫或刪除。
- 每份來源應記錄標題、作者/機構、網址或檔名、日期、取得日期及使用權/授權資訊。
- 請至少準備五篇可合法使用的資料，才可宣稱完成本次作業的 ingest 要求。
- 不要上傳未獲授權的完整講義、付費標準或他人受著作權保護的教材。
- 團隊文件先取得適當同意，並移除個資、密碼、API Key、客戶資訊及機密資料。

建議分類：
- `software_engineering/`
- `data_structures/`
- `other_topics/`

目前資料夾尚未放入五篇正式來源。
